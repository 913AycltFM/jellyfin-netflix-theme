QUICK SETUP

Install in Jellyfin

  1. Open Jellyfin and sign in with an administrator account.
  2. Open Dashboard → General → Custom CSS.
  3. Paste the import line above and save.
  4. Reload the Jellyfin web interface. If needed, clear the browser cache.

This is a CSS-only theme. Jellyfin clients that do not load the server's web CSS may not display the theme. Selectors can vary between Jellyfin versions, so test the theme on your own server.
